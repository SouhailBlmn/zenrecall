# Zen Recall

## Description
Zen Recall is a browser extension designed to help users manage their browsing sessions by storing and restoring opened tabs and windows. It acts as a temporary fix for the ongoing Zen browser history bug, ensuring that users can easily access their previously opened tabs.

## Features
- Automatically saves opened tabs and windows.
- Restores all previously opened tabs and windows with a single click.
- Clear all stored tabs with a dedicated button.
- User-friendly interface with a simple popup for managing tabs.

## Installation
1. Download the extension files.
2. Open your browser and navigate to the extensions page.
3. Enable "Developer mode" (usually found in the top right corner).
4. Click on "Load unpacked" and select the directory containing the extension files.

## Usage
- Click on the Zen Recall icon in your browser toolbar to open the popup.
- View the list of currently stored tabs.
- Use the "Clear All Stored Tabs" button to remove all stored tabs.
- Click "Restore All Tabs" to reopen all previously stored tabs.
